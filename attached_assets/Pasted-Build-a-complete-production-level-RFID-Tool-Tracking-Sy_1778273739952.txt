FEATURE REQUIREMENTS
====================

1. AUTHENTICATION

* Register API
* Login API
* JWT token generation
* Protected routes
* Password hashing using bcryptjs

2. TOOL MASTER (CRUD)
   Each tool must contain:

* toolId
* name
* category
* status
* createdAt

Status values:

* Available
* Issued
* Missing

3. ISSUE TOOL
   Input:

* toolId
* userId

Logic:

* Check tool exists
* Check tool available
* If already issued return error
* Mark status as Issued
* Save transaction

4. RETURN TOOL
   Input:

* toolId

Logic:

* Check tool exists
* If tool not issued return error
* Mark status as Available
* Save transaction

5. INVENTORY RFID SCAN
   API:
   POST /scan

Input:
{
"scannedTools": ["T001", "T002"]
}

Logic:
Compare scanned tools with database tools.

Return:
{
"correctTools": [],
"missingTools": [],
"extraTools": []
}

Example:

Database:
T001
T002
T003

Scanned:
T001
T004

Output:
Correct:
T001

Missing:
T002
T003

Extra:
T004

6. DASHBOARD
   Display:

* Total tools
* Issued tools
* Missing tools
